## 🚀 Começar Rapidamente

```bash
# Criar projeto
npx create-video@latest

# Adicionar transições
npx remotion add @remotion/transitions

# Adicionar legendas
npx remotion add @remotion/captions

# Renderizar vídeo
npx remotion render MyComp out/video.mp4

# Renderizar imagem
npx remotion still MyComp out/image.png
```

📋 CARACTERÍSTICAS DE TODOS OS EXEMPLOS:

   ✅ cURL/bash:
   • Comandos completos e funcionais
   • Headers corretos (Content-Type: application/json)
   • JSON formatado corretamente
   • client_id único para cada exemplo
   • Comentários explicando cada parâmetro
   • Loop de espera para processamento
   • Download automático de outputs

   ✅ Python:
   • Código completo e funcional
   • Importa do utils.py existente
   • Conexão WebSocket para monitoramento
   • Upload de inputs (quando aplicável)
   • Download automático de outputs
   • Salva em: user/outputs/{data}/{exemplo}/
   • Tratamento de erros
   • Docstrings explicativas
   • Print de progresso
   • Fix de encoding UTF-8 para Windows
